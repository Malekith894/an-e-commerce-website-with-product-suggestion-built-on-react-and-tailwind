# E-Commerce Website with Product Recommendations

A responsive e-commerce web application built with React and Tailwind CSS. The application allows users to browse products, explore product details, filter products by price and category, and discover related products based on their categories.

Product data is fetched from the [Fake Store API](https://fakestoreapi.com/products) using Axios.

## ✨ Features

- **Product Catalog:** Browse products fetched from the Fake Store API.
- **Product Details:** View detailed information about individual products.
- **Category-Based Recommendations:** Discover related products belonging to the same category as the currently selected product.
- **Price Filtering:** Filter products based on price.
- **Category Filtering:** Browse and filter products by category.
- **Shopping Cart:** Add and remove selected products.
- **Local Storage:** Persist shopping selections using browser LocalStorage.
- **Responsive UI:** Responsive layouts designed for different screen sizes.
- **Page Navigation:** Separate pages for the menu, shop, and product details.

## 🛠️ Technologies Used

- **React** – Building reusable and component-based user interfaces.
- **JavaScript** – Application logic and functionality.
- **Vite** – Development environment and build tooling.
- **Tailwind CSS** – Styling and responsive layouts.
- **Axios** – Fetching product data from external APIs.
- **React Router DOM** – Navigation between application pages.
- **LocalStorage** – Client-side data persistence.
- **Fake Store API** – External product data source.

## 📡 API Integration

The application uses the Fake Store API to retrieve product information.

**Endpoint:**

[https://fakestoreapi.com/products](https://fakestoreapi.com/products)

Axios is used to make HTTP requests and retrieve product data for the store.

## 💾 Data Persistence

LocalStorage is used to maintain the user's shopping selections between page refreshes.

The stored information is also used to update the shopping-related information displayed in the navigation bar.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Malekith894/an-e-commerce-website-with-product-suggestion-built-on-react-and-tailwind.git
```

### 2. Navigate to the project directory

```bash
cd an-e-commerce-website-with-product-suggestion-built-on-react-and-tailwind
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 🎯 Project Purpose

This project was developed to practice building a complete frontend e-commerce application using React. It focuses on reusable components, API integration, client-side data persistence, product filtering, and dynamic product recommendations.
