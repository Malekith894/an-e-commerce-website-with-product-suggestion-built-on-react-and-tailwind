# an-e-commerce-website-with-product-suggestion-built-on-react-and-tailwind
The project is built using Vite. the data used for this store is taken from "fakestoreapi.com/products". Axios was implemented to fetch the data because of its higher speed. the project consists of three pages. the menu, shop and item details. tailwind was used as the main styling framework for components. Local storage was used to save data. Moreover, context Api was not used in the project, instead local storage was used to pass data in the navbar. items shopped by the user would then be removed or added using local storage.
